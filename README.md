# MentorAI

> **The AI That Learns How You Learn**

---

## 🚀 Overview

MentorAI is an adaptive AI learning platform that personalizes **how it teaches**, not just **what it teaches**.

Unlike traditional AI assistants that provide generic responses, MentorAI continuously builds a **Learning Twin**—a dynamic model of each learner's knowledge, confidence, misconceptions, and preferred learning style.

Every explanation, quiz, revision plan, and learning roadmap is generated based on that evolving profile.

---

## 💡 The Problem

Students learn using multiple disconnected resources:

- 📚 PDFs
- 🎥 YouTube
- 📖 Documentation
- 🤖 ChatGPT
- 💻 Coding Platforms
- 📝 Personal Notes

Today's AI assistants answer questions, but they don't understand **how each student learns**.

---

## 🎯 Vision

> **Every student learns differently. Every explanation should too.**

MentorAI aims to become an AI mentor that continuously adapts its teaching strategy based on each student's learning behaviour.

The goal is **not** to maximize answers.

The goal is **to maximize understanding.**

---

## ⭐ Core Innovation — Learning Twin

The Learning Twin is MentorAI's core intelligence.

Instead of storing only user information, it continuously models:

- Knowledge Level
- Confidence
- Weak Topics
- Strong Topics
- Learning Style
- Quiz Performance
- Learning Speed
- Common Misconceptions
- Learning History
- Study Goals

Before answering a question, MentorAI first asks:

> **"What's the best way to teach this student?"**
